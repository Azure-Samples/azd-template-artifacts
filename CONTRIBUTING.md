# Contributing

Thank you for your interest in contributing! This project is better because of the people who share ideas, report issues, improve guidance, and submit fixes. Whether you are correcting a typo or proposing a larger improvement, we appreciate the time and care you bring to the open source community.

Contributions and suggestions are welcome. Most contributions require you to agree to a [Contributor License Agreement](https://cla.opensource.microsoft.com/) declaring that you have the right to grant us permission to use your contribution. A bot will provide instructions when you open a pull request if an agreement is required.

This project follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/). See the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) or contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with questions.

## Report an issue

Before opening an issue:

1. Search the [existing issues](https://github.com/Azure-Samples/azd-template-artifacts/issues).
2. Identify the affected document or section.
3. Include reproduction steps for broken commands or examples.
4. Link to current authoritative documentation when proposing a policy or technical recommendation.

Do not report security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Submit a change

1. Fork the repository and create a branch from the default branch.
2. Make a focused change that follows the guidance conventions documented in [README.md](README.md).
3. Check links, heading anchors, commands, and configuration examples affected by the change.
4. Open a pull request using the repository template and respond to review feedback.

Use **MUST** only for a verified requirement. Use **SHOULD** for a recommended default and **MAY** for an optional approach. Pull requests that add or change requirements should identify the validator, collection policy, or platform constraint that enforces them.

Thank you for helping make `azd` templates more useful, approachable, and reliable for everyone.
