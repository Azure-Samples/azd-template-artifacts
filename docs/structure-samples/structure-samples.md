# Structure samples

These samples show common repository layouts for Azure Developer CLI (`azd`) templates by language.

Use them as examples, not as rigid blueprints.

## What every sample is illustrating

- the placement of `azure.yaml`,
- where infrastructure assets typically live,
- how application code and supporting files are commonly organized,
- where optional assets such as dev containers or workflow files may fit.

The exact shape can vary by framework or platform. What matters is that the repository still satisfies the core `azd` requirements described in [docs/readme.md](../readme.md).
